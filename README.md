# סימולטור מתח ממברנה

אפליקציה אינטראקטיבית להמחשת השפעת ערכיות היון וכיוון הזרם על מתח הממברנה.

## הפעלה מקומית

פתחו את `index.html` בדפדפן. האפליקציה עצמאית ואינה דורשת התקנה או חיבור לאינטרנט.

## פרסום ב־GitHub Pages

הקבצים מוכנים לפרסום ישירות משורש הענף `main`:

1. העלו את כל הקבצים למאגר GitHub.
2. פתחו **Settings → Pages**.
3. תחת **Build and deployment** בחרו **Deploy from a branch**.
4. בחרו בענף `main`, בתיקייה `/ (root)`, ושמרו.

האתר אינו משתמש בשירותי צד שלישי או בתהליך בנייה.
